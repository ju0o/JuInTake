# JuIntake

https://github.com/ju0o/JuIntake

공개 GitHub 저장소입니다. 정적 사이트(GitHub Pages)를 `main` 브랜치 루트에서 제공합니다.

## 배포 설정

- 브랜치: `main`
- 경로: `/` (저장소 루트)
- 빌드 도구: 없음 (정적 HTML 그대로)

## 로컬 작업 경로

```
~/projects/Public/JuIntake
```

## 구조

```
index.html              페이지 진입점 (운영 파일로 교체 예정)
assets/css/style.css    기본 스타일
```

## 규칙

- 비밀 정보(키, 토큰, `.env`)는 절대 커밋하지 않습니다.
- 운영 파일은 이 저장소의 `main` 브랜치 루트에 두어야 합니다.
